## เว็บไซต์นี้สามารถทำอะไรได้บ้าง

### 1. แสดงผลแบบหนังสือพลิกหน้า 3 มิติ (Interactive Page-Flip)
- จำลองการเปิด–พลิกหน้าหนังสือแบบสมจริงด้วยไลบรารี `St.PageFlip` (`page-flip@2.0.7`) มีปกแข็งหน้า–หลัง เงาพับหน้ากระดาษ และการคลิก/ลากมุมกระดาษหรือปัดเพื่อเปลี่ยนหน้า
- หน้าปกและพื้นหลังตกแต่งด้วยลายกริด Blueprint และเฟืองวิศวกรรมหมุนช้าๆ

### 2. นำเสนอข้อมูล 2 ภาษาคู่ขนาน (Bilingual Spread: EN / TH)
- สำหรับคณาจารย์แต่ละท่าน **หน้าซ้าย** จะแสดงข้อมูลและผลงานวิจัยภาษาอังกฤษ (`EN`) และ **หน้าขวา** จะแสดงข้อมูลและผลงานวิจัยภาษาไทย (`TH`) คู่กัน
- โครงสร้างเล่มถูกจัดหน้าให้อัตโนมัติเป็นเลขคู่เสมอ (`6 + 2 * N` หน้า) ประกอบด้วย:
  1. หน้าปก (Front Cover)
  2. ปกใน (Inside Cover) พร้อมภาพอาคารคณะ
  3. สารจากคณบดี (Foreword)
  4. สารบัญผลงานวิจัย (Contents) แยกหมวดตามภาควิชา (`Civil`, `Industrial`, `Mechanical`, `Electrical & Computer`) โดยเรียงรายชื่อจากตำแหน่งทางวิชาการสูงสุดลงมา พร้อมคำแนะนำการใช้งาน
  5. หน้าคั่นหมวด (Engineering Research Divider)
  6. หน้าผลงานวิจัยคณาจารย์แต่ละท่าน (คนละ 2 หน้า: EN / TH)
  7. ปกหลัง (Back Cover)

### 3. ระบบนำทางและข้ามหน้าหลายรูปแบบ (Navigation & Jump Controls)
- **ปุ่มเปลี่ยนหน้า:** ปุ่มลูกศร `←` / `→` บนแถบเมนูด้านบน และรองรับปุ่มลูกศรซ้าย–ขวาบนคีย์บอร์ด (`ArrowLeft` / `ArrowRight`)
- **พิมพ์เลขหน้าโดยตรง:** กรอกหมายเลขหน้าในช่องตัวเลขด้านบนแล้วกด `Enter` เพื่อพลิกไปหน้านั้นทันที
- **เมนูข้ามหมวดหมู่ (`Jump to section`):** เลือกข้ามไปยังหน้าปก สารบัญ รายชื่อคณาจารย์แต่ละท่าน หรือปกหลัง
- **สารบัญแบบโต้ตอบได้:** คลิกที่รายชื่ออาจารย์หรือหัวข้อในหน้าสารบัญ (หน้า 4) เพื่อพลิกไปยังหน้านั้นทันที
- **กลับหน้าปกด่วน:** คลิกที่โลโก้หรือชื่อคณะบริเวณมุมซ้ายบนเพื่อกลับไปหน้าปก
- **เปิดหน้าเฉพาะผ่าน URL:** รองรับ Query Parameter `?page=N` เช่น `?page=6` เพื่อเปิดตรงไปยังหน้าที่ต้องการได้ทันที

### 4. ระบบค้นหาข้อมูลแบบเรียลไทม์ (Live Search)
- ช่องค้นหา `ค้นหาอาจารย์ / งานวิจัย...` บนแถบด้านบน สามารถค้นหาได้จากชื่ออาจารย์ (ไทย/อังกฤษ), ตำแหน่งทางวิชาการ, ภาควิชา, หัวข้องานวิจัย, ประวัติ, ความสนใจ และบทคัดย่อ
- แสดงรายการผลลัพธ์พร้อมเลขหน้า และคลิกเพื่อพลิกไปยังหน้าของอาจารย์ท่านนั้นได้ทันที

### 5. สลับโทนสีพื้นหลัง Blueprint (Light / Dark Mode)
- ปุ่ม `🌓` บนแถบด้านบนสำหรับสลับระหว่างโหมดสว่าง (Light Blueprint) และโหมดมืด (Dark Blueprint)
- บันทึกการตั้งค่าธีมที่เลือกลงใน `localStorage` (`NU_ENG_EBOOK_THEME`) และรองรับการตั้งค่าโทนสีของอุปกรณ์ (`prefers-color-scheme`)

### 6. รองรับการแสดงผลทุกขนาดหน้าจอ (Responsive Design & Touch Navigation)
- คำนวณสัดส่วนหนังสือให้พอดีกับขนาดหน้าจออัตโนมัติและปรับขนาดใหม่เมื่อย่อ–ขยายหน้าต่าง
- หน้าจอกว้าง (`>= 760px`) แสดงผลแบบเปิดหนังสือ 2 หน้าคู่ (Spread) และหน้าจอมือถือ/จอแคบ (`< 760px`) ปรับเป็นโหมดหน้าเดี่ยวที่ปัดเปลี่ยนหน้าได้สะดวก
- **รองรับการแตะเพื่อเปลี่ยนหน้าบนมือถือ iPad และแท็บเล็ต:** แตะครึ่งซ้าย/ครึ่งขวาของหน้าหนังสือเพื่อพลิกไปหน้าก่อนหน้าหรือหน้าถัดไป (พร้อมปุ่ม `‹ ก่อนหน้า` / `ถัดไป ›` ด้านล่างที่แตะได้ถนัดมือและเอฟเฟกต์ลูกศรตอบสนองขณะแตะ โดยไม่รบกวนการแตะเลือกรายชื่ออาจารย์ในสารบัญ)
- รองรับการลดแอนิเมชันสำหรับผู้ใช้ที่เปิดโหมด `prefers-reduced-motion`

### 7. ปรับแต่งและเพิ่มข้อมูลอาจารย์ได้ง่าย (Data-Driven)
- ข้อมูลทั้งหมดของ E-Book ถูกแยกเก็บไว้ใน `js/data.js` (`window.DEFAULT_EBOOK_DATA`)
- สามารถแก้ไขข้อความหน้าปก สารจากคณบดี ข้อมูลติดต่อ เปลี่ยนรูปภาพในโฟลเดอร์ `img/` หรือเพิ่มข้อมูลอาจารย์ท่านใหม่ได้โดยไม่ต้องแก้ไขโครงสร้างโค้ดหลัก ระบบจะสร้างหน้า สารบัญ และรายการค้นหาให้อัตโนมัติ

## โครงสร้างไฟล์ในโปรเจกต์

```text
.
├── index.html      # หน้าหลักของเว็บ E-Book และแถบควบคุมด้านบน
├── README.md       # เอกสารอธิบายความสามารถและการใช้งานเว็บไซต์
├── css/
│   └── style.css   # สไตล์ Blueprint, หน้าคู่ 2 ภาษา, โหมดสว่าง/มืด และ Responsive
├── js/
│   ├── data.js     # ข้อมูลหน้าปก, คณบดี, รายชื่ออาจารย์ และงานวิจัย (แก้ไข/เพิ่มได้ที่นี่)
│   └── main.js     # ระบบสร้างหน้าอัตโนมัติ, St.PageFlip, ค้นหา, นำทาง และสลับธีม
└── img/            # ไฟล์รูปภาพตราคณะ อาคาร คณบดี ภาพอาจารย์ และภาพประกอบงานวิจัย
```

## วิธีเปิดทดสอบบนเครื่อง (Local Preview)

เนื่องจากเว็บนี้เป็น Static Web App (HTML/CSS/JS) จึงสามารถรันผ่านเว็บเซิร์ฟเวอร์จำลองหรือเปิดผ่าน GitHub Pages ได้ทันที:

```bash
python3 -m http.server 8090
```

จากนั้นเปิดเบราว์เซอร์ไปที่ `http://localhost:8090`
